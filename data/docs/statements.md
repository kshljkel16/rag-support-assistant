# Statements and account confirmation

You can download statements as PDF or CSV in the app: Profile → Documents → Statements. Statements are available for any period since you opened your account, up to the last 7 years.

You can also download an account confirmation letter showing your name, address, sort code and account number. Banks, landlords and employers usually accept it as proof of address.

Statements are generated in English only. If you need a stamped statement for a visa application, contact support; this takes up to 3 working days.
