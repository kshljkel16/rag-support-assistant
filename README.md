# RAG Support Assistant (work in progress)

A customer-support assistant for **Orbit**, a fictional bank: it answers only from the help
centre, cites its sources and refuses questions the help centre doesn't cover. Evaluated on
retrieval quality, answer correctness, refusals, cost and latency, against simple baselines.

Results will be added as the project progresses. See `GUIDE.md` for the build steps.

*Orbit and all help-centre articles in `data/docs/` are fictional and written for this project.*
